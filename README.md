# Albergue Casa Arcoiris SPA

Este proyecto es una aplicación de una sola página (SPA) creada para el albergue Casa Arcoíris. La aplicación está desarrollada con [Vue.js](https://vuejs.org/) y usa [Tailwind CSS](https://tailwindcss.com/) para los estilos. Incluye secciones para misión, visión, servicios, donaciones, contacto, entre otras.

## Características

- **Inicio**: Con un carrusel de imágenes y noticias destacadas.
- **Acerca de Nosotros**: Muestra imágenes y una descripción del albergue, con fotos que cambian aleatoriamente.
- **Donaciones**: Integración con PayPal para recibir contribuciones.
- **Servicios**: Información sobre los servicios que ofrece el albergue, incluyendo salud y apoyo legal.
- **Contacto**: Un formulario que envía un correo electrónico a la institución.

## Configuración del Proyecto

### Instalación de dependencias
Instala las dependencias necesarias ejecutando el siguiente comando:
```
npm install
```

### Compilar y recargar en desarrollo
```
npm run serve
```

### Compilar y minimizar para producción
```
npm run build
```

### Lint y correcciones de estilo
```
npm run lint
```
